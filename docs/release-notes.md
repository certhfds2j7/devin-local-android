## 0.4.0

- 代理回答右下角支持复制纯文本、富文本、Markdown 原文、全部或单个代码块；保留代码缩进，公式纯文本采用 LaTeX 内容，富文本含表格和 MathML（粘贴效果由目标应用决定）。
- 支持全屏查看单段回答，保持中文富文本、文件链接、流式更新及复制入口；返回时保留原对话滚动位置。
- 用户消息右下角支持确认删除本机这一轮提问、对应回答及工具记录。保留前后轮次和项目文件；忙碌时禁止删除，恢复原会话不会重复显示已删除记录。
- 增加“从此处重新开始”入口及当前核心不支持提示。实测官方 ACP 未提供按步骤分叉接口、未公布 fork / steps 命令，因此本版不能实际撤回官方上下文或执行按轮次分叉。入口不会发送伪造分叉提示、修改官方数据库或回滚项目文件。

## 0.3.0

- 项目卡片和历史对话列表支持重命名，当前对话标题可直接改名。名称保存在本客户端，文件路径及会话编号保留。
- 支持删除项目，需输入当前项目名称确认；清理该项目的本机文件、Git、附件及本客户端历史记录。
- 运行中的任务、打开的终端及核心升级会阻止删除；删除与文件传输、Git 操作、会话连接按项目串行处理。

## 0.2.0

- 对话顶部显示模型、模式和思考强度，支持官方提供的强度选项及动态更新。
- 通过系统文件选择器上传多个附件，保留附件引用，按官方能力发送图片、文本或资源链接。
- 离线 Markdown、LaTeX、表格、任务列表、脚注和代码高亮；支持项目内图片。
- 从对话中的文件链接或项目文件列表下载，并通过系统选择保存位置。
- 单独删除一条本机历史对话，确认后执行；保留项目文件，禁止删除运行中的会话。
- 兼容中文与空格文件名的编码下载链接，修复恢复会话时官方重放消息造成的重复回复。

## 0.1.7

- 对话断线后自动重连并按事件序号补回消息，返回界面时恢复连接，避免一直显示过期的“处理中”状态。
- 切换项目或会话时忽略旧连接的迟到回调，避免混入其他会话内容。
- 在对话中显示本地工具的文本输出，方便核对实际执行结果。
